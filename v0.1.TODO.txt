REFACTOR
    v0.1.7
        [ ] BIG REFACTOR - one manager at a time
        
        convert to service model to clean up manager codependencies...
        
        Here's the simplified step-by-step plan:
            
            Create AppService
                Create a central service coordinator
                This will be the single source of truth for all services
            
            For Each Manager (TaskManager, NavManager, etc.)
                Create a new Service class
                Move all business logic from Manager to Service
                Remove all @Published properties from Service
                Remove all direct dependencies on other managers from Service
                Create a new (View?)Manager class that wraps the Service
                Move all UI state management to the new Manager
                Make Manager delegate to Service for business logic
            
            Update Views
                Update views to use the new Managers
                Inject AppService where needed
                Remove direct manager-to-manager dependencies
            
            Clean Up
                Remove old Manager classes
                Remove any remaining direct dependencies between services
                Update any tests to use the new structure
            
            The key principle is: Services handle business logic, (View?)Managers handle UI state, and AppService coordinates everything.
