# 🧪 Soft Launch Checklist – Tamagotchi + Todo App

## ✅ Pre-Soft Launch
- [ ] Test all core features manually (e.g., feeding, completing a task, progress UI)
- [ ] Crash reporting integrated (e.g., Firebase Crashlytics, Sentry)
- [ ] Basic analytics live (task completed, pet fed, user retention)
- [ ] Onboarding flows tested
- [ ] Empty states and edge cases handled gracefully
- [ ] App Store metadata filled out (minimal SEO/keywords for now)
- [ ] App review prompt implemented (but shown only after success action, like completing 3 tasks)
- [ ] TestFlight build distributed and stable

## 🚀 Soft Launch (Live on App Store but unannounced)
- [ ] App available in 1–2 test regions (or limited keyword discoverability)
- [ ] Share app privately with trusted testers (outside TestFlight)
- [ ] Monitor crash reports daily
- [ ] Monitor analytics (especially retention, session length, feature usage)
- [ ] Start collecting App Store reviews from early users

## 🔁 Iterate
- [ ] Fix any high-severity bugs or onboarding drop-offs
- [ ] Improve any unclear UX based on real feedback
- [ ] Validate engagement: are users completing tasks, returning, interacting with the pet?

## 📣 Prep for Public Launch
- [ ] Add final App Store keywords & optimized description
- [ ] Add promotional assets (screenshots, preview video, icon polish)
- [ ] Submit for App Store editorial (optional but helpful)
- [ ] Prep launch tweet/post/email/etc.
- [ ] Confirm scalability (e.g., any backend rate limits or push notification handling)

## 🏁 Launch Day
- [ ] Announce to your audience (social, newsletter, etc.)
- [ ] Monitor servers and crash reports closely
- [ ] Engage with early feedback and respond to reviews if needed
